# Challenges

- **13-A 5-Level Paging:** ขยาย page-walk simulatorด้วย LA57 mode.
- **13-B Huge Pages:** เพิ่ม 2 MiB/1 GiB mappingsและ translation rulesใน simulator.
- **13-C IDT Encoder:** serialize IDT gateเป็น exact 16 bytesและ decodeกลับ.
- **13-D Page Fault Decoder:** รับ page-fault error codeแล้วอธิบาย present/write/user/reserved/instruction bits.
- **13-E Early Memory Plan:** จาก mock Multiboot memory map สร้าง reserved/usable frame rangesอย่าง deterministic.
