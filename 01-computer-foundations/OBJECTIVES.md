# Objectives

เมื่อจบบทนี้ ผู้เรียนควรสามารถ:

- แปลง decimal, binary และ hexadecimal ด้วยมือ
- อธิบาย unsigned range และ two's-complement signed range
- แยก representation ออกจาก interpretation
- ใช้ AND/OR/XOR/NOT และ bit masks
- อธิบาย shifts และข้อจำกัดของการคิดว่า shift = คูณ/หารเสมอ
- อ่าน ASCII byte values และเข้าใจว่า text encoding กว้างกว่า ASCII
- มอง memory เป็น addressable bytes และอ่าน multi-byte object
- อธิบาย little/big endian และ alignment concept
- อธิบาย CPU/register/instruction และ simplified Fetch→Decode→Execute
