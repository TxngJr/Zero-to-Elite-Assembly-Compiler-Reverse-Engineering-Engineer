# Common Mistakes

- stringหนึ่งตัวพิสูจน์ function behaviorทั้งหมด
- symbol name = guaranteed semantics
- ทุก source functionต้องมี functionหนึ่งตัวใน O2
- stripped = ไม่มี metadataใดเหลือ
- source switch = jump tableแน่นอน
- base+index*4 = int arrayแน่นอน
- dynamic runหนึ่งครั้งครอบคลุมทุก path
- runtime PIE address = link-time addressตรง ๆ
- compiler fingerprintจาก patternเดียว
- pseudocodeเติม intentที่ evidenceไม่รองรับ
- วิเคราะห์ targetโดยไม่เช็ค authorization/provenance
