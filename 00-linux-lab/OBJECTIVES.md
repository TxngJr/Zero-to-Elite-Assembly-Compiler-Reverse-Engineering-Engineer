# Objectives

เมื่อจบบทนี้ ผู้เรียนควรสามารถ:

- อธิบายความต่างระหว่าง terminal, shell, command, program และ process
- เดิน filesystem ด้วย absolute/relative paths และอ่าน metadata ของ file
- อธิบาย permission `rwx`, owner/group/other และ octal mode
- อธิบาย PATH และ environment variables โดยไม่แก้ shell config ถาวรโดยไม่จำเป็น
- แยก stdin/stdout/stderr และต่อ pipeline ได้
- ตรวจ process, PID, PPID, exit status และ signal concept
- สำรวจ `/proc` อย่างปลอดภัย
- แยกบทบาท preprocessor, compiler, assembler และ linker ใน C build pipeline
- ใช้ `file`, `readelf`, `objdump`, `nm` เพื่อ inspection ขั้นต้น
- เขียน Makefile เล็ก ๆ และใช้ Git พื้นฐาน
- เริ่ม debug C ด้วย GDB
