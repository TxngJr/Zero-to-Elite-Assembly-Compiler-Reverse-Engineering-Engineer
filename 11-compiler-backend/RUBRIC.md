# Rubric — Compiler Backend

| Category | Points | Required evidence |
|---|---:|---|
| Concepts / mental model | 20 | อธิบายด้วยภาษาตัวเอง + เชื่อม concepts |
| Prediction / reasoning | 10 | prediction ก่อนทดลองอย่างน้อย 3 จุด |
| Lab evidence | 20 | commands/code/output ที่ตรวจย้อนกลับได้ |
| Implementation / modification | 25 | สร้าง/แก้ local code และมี regression/test |
| Inspection / debugging | 15 | ใช้ chapter tools หา state/artifact/root cause |
| Explanation / limitations | 10 | why + สิ่งที่ยังไม่ได้พิสูจน์ |

**Pass:** ≥85/100, Implementation ≥18/25, Lab evidence ≥14/20.

`make test` ผ่านแต่ไม่มี practical explanation ไม่ถือว่าผ่าน mastery.
