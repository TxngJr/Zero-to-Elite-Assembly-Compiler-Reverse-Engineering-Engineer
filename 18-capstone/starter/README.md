# Capstone Starter Workspace

โฟลเดอร์นี้ตั้งใจ **ไม่มี reference solution**.

ให้ copy template นี้ออกไปเป็น working directory ของคุณ:

```bash
cp -a 18-capstone/starter capstone-submission
```

จากนั้นทำตาม [../ASSIGNMENT.md](../ASSIGNMENT.md).

## Rule

อย่าแก้ generated `18-capstone/build/` แล้วถือว่าเป็น capstone implementation. การเปลี่ยนต้องอยู่ใน source/tests ของ subsystem ที่เลือก และต้องมี patch/evidence.
