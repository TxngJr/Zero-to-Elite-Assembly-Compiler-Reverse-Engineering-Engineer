# Objectives

เมื่อจบ Capstone ควรสามารถ:

- trace one program from EliteLang source to executing ELF
- explain lexer/parser/type-checking/IR/backend responsibilities
- inspect generated IR and x86-64 assembly
- explain SysV AMD64 ABI decisions in generated code
- inspect executable ELF headers/sections/symbols/disassembly
- build and inspect EliteOS64 kernel image
- validate Multiboot2 header mechanically
- explain 32-bit boot → long mode → kernel_main
- distinguish Chapter 14 kernel implementation from Chapter 15 algorithm simulators
- explain scheduler, COW, IPC and VFS models
- perform static/dynamic RE on authorized course binaries
- separate facts, hypotheses and unknowns in RE reports
- run defensive parser regression/fuzz/sanitizer workflows
- explain root cause vs crash site
- generate reproducible artifact hashes
- create a final engineering report/portfolio showing evidence rather than claims
- identify technical debt and next engineering steps in compiler/OS/tooling
