# Common Mistakes

- treating capstone as another reading chapter instead of integration evidence
- claiming production readiness from educational tests
- confusing compiler status with generated program status
- comparing PIE runtime addresses directly to static addresses
- assuming QEMU success means universal hardware support
- claiming Chapter 15 simulators are already integrated kernel subsystems
- reconstructing RE semantics without labeling uncertainty
- treating sanitizer/fuzzer clean runs as proof of security
- writing portfolio claims without commands/tests/artifacts
- hiding limitations instead of documenting them
- running RE/security exercises on unauthorized targets
