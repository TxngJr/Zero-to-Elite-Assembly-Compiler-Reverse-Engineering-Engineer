# Challenges

- **18-A EliteC Differential Harness:** implement an AST/IR interpreter and compare hundreds of generated valid programs against compiled execution.
- **18-B Real Register Allocation:** integrate linear-scan allocation into EliteC and quantify stack-load reduction.
- **18-C EliteOS User Task:** integrate robust exception frames, TSS, 4 KiB mapper and a single ring-3 task in a reviewable patch series.
- **18-D Kernel Scheduler Integration:** bring Chapter 15 scheduling ideas into EliteOS while keeping serial boot regression tests.
- **18-E Capstone RE Blind Test:** have another person compile a small authorized program from source you do not inspect, then reconstruct behavior and compare with source afterward.
- **18-F Defensive Fuzz Campaign:** connect parser-lab to a coverage-guided local fuzzer, minimize any failures and turn them into regression tests.
- **18-G Reproducible Release:** create a tagged release process that records tool versions, hashes and generated artifacts without committing build noise.
